# りすぺく島RPG Ver.0.36

## ギョウ
ギョウを戦闘メンバーとして実装。加入後の戦闘では主人公・スズマル・ユーノに続いて行動します。

### スキル
- 岩守り：自分の防御力アップ
- かばう：主人公への攻撃を代わりに受ける
- 挑発：敵から狙われやすくなる
- 土脈吸収：ダメージを受けるとMP回復
- 守りの呼吸：自分を回復しながら防御
- 二段突き：槍で単体へ2回攻撃
- 迎撃の構え：攻撃を受けるとカウンター

スキル画面にギョウ用タブを追加し、SPで習得できます。

## 村長との特訓
決戦準備中、たけぞ村の老村長とギョウの特訓イベントを追加。

奥義「大守護」を習得します。
大守護は1ターン、仲間全員への攻撃をギョウが引き受ける強力な身代わり技です。
消費MPは16。集中攻撃を受ける危険もあります。

## 戦闘上の特徴
挑発 → 被弾 → 土脈吸収でMP回復 → 守りの呼吸 / 迎撃
という、攻撃を受けるほど技を回しやすいタンク型です。
