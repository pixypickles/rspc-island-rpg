# りすぺく島RPG Ver.0.22

## Aボタン修正
通常フィールドでAボタンを押した時の動作を統一しました。

- サーカス団→ぶりふぉ村の森：メニュー
- ぶりふぉ→さるびえ：メニュー
- 火山麓の洞窟：メニュー
- さるびえ→さるびび：メニュー
- 村の中：近くの店や場所を調べる

メニューを閉じた時は、開いた元のフィールドへ戻ります。

## 敵ターン修正
2人パーティでは
主人公 → スズマル → 敵
を必ず通るよう再調整しました。

スズマルの
- 通常攻撃
- 火炎斬り
- 火走り
- 防御
- 回復薬
のどれを選んでも、行動後は必ず敵ターンへ進みます。

敵ターンでは
- 「敵のターン」
- 「ENEMY TURN」
- 主人公 / スズマルの上に赤い被ダメージ数値
を表示します。

これで敵が実際に攻撃しているか、画面上でも分かりやすくしています。
