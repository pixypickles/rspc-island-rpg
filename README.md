# りすぺく島RPG Ver.0.20

## 修正：2人パーティの行動順
主人公 → スズマル → 敵
の順を明示的に固定しました。

さるびび村手前を含む、スズマル同行中のすべての複数戦で、
主人公だけ行動して敵ターンへ飛ばないよう修正しています。

## 味方の被ダメージ表示
敵から攻撃を受けた時、
- 主人公の上に「-12」
- スズマルの上に「-8」
のような赤いダメージ数値を表示。

メッセージ欄にも誰が何ダメージ受けたか表示します。

## 防衛隊長
防衛隊長を汎用キャラから、
ユーノとは毛色の違うイタチ族キャラへ変更。
濃い茶系の毛色と、防衛隊長らしいターコイズ＋ネイビー衣装です。

## さるびび村の店
村到着後に歩けるエリアを追加。

武器屋：
- 風切りの小剣 85G
- 主人公の攻撃力 +4
- 1回のみ購入

道具屋：
- 回復薬 20G
- 何個でも購入可能
- 戦闘中、味方1人のHPを25回復
