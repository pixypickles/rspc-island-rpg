# りすぺく島RPG Ver.0.46

## ギョウのスキルツリー表示を修正

原因：
Ver.0.45ではギョウの加入判定は正しくなりましたが、
スキル画面のキャラクター切替が主人公・スズマル・ユーノの3人用のままで、
ギョウ用タブと描画処理が抜けていました。

修正：
- スキル画面上部を4人タブに変更
- ギョウ加入後だけ「ギョウ」タブを有効化
- ギョウのスキルツリーを表示
- SPを使って各スキルを習得可能

表示スキル：
- 岩守り
- かばう
- 挑発
- 土脈吸収
- 守りの呼吸
- 二段突き
- 迎撃の構え

「大守護」は通常SPではなく、村長との特訓イベントで解放される奥義として下部に表示します。
