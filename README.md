# りすぺく島RPG Ver.0.43

## ギョウが消える問題を修正

原因：
ギョウ加入後の `gyouJoined` が通常セーブデータに保存されていませんでした。
そのため「つづきから」で再開するとギョウだけ未加入扱いに戻り、
メニューと戦闘の両方から消えていました。

修正：
- `gyouJoined` をセーブ・ロード対象に追加
- Ver.0.42以前のセーブでも、ギョウ加入後のストーリー地点なら自動的に加入済みへ補修
- メニュー表示時にもストーリー進行から加入状態を安全確認
- 大ドリアングマ戦開始時にも加入状態を補修

## 戦闘
4人の戦闘参加を再確認し、

戦闘画面にも
