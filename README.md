# りすぺく島RPG Ver.1.06

- ぶりふぉ村長の「のう、ダッシュミウよ？」と、その場にいないダッシュミウの返事を削除。
- サーカス団で船を出してもらった後、海賊戦前に「ちぇすたぴサーカス団の船」のワンカットを追加。
- 船のワンカットでAを押すと海賊拠点の連戦へ。
- 追加海賊戦クリア後はサーカス団へ戻らず、ぶりふぉ村へ帰還。
- 撃破後は追加海賊イベントを再発生させない。
- クラウスをサイボーグ化。HPを 2600 + Lv20超過分×85 とし、ドラゴン以上の耐久力を持つ裏ボス枠へ変更。
- クラウスの見た目を半分機械化＋マシンガン腕に変更。
- 船長（ペンギン）と副船長（シロクマ）に明確な点の目を追加し、専用ボスグラフィックを使用。
