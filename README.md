# りすぺく島RPG Ver.0.16

## さるびえ村・戦闘UI改修

### 儀式
- 鍛冶場前から完全に分離
- 専用の「火鎮め広場」を新設
- 中央祭壇、石畳、篝火のある儀式専用背景へ変更

### さるびえ村で買い物
到着後、村を少し歩けるようにしました。

武器屋・鍛冶場：
- 火打ちの小剣 60G
- 主人公の攻撃力 +3
- 一度のみ購入可能

道具屋：
- スキルの実 80G
- SP +1
- 一度のみ購入可能

敵を倒すと経験値に加えてGも獲得します。

### 2人戦闘UI
マグマガメ戦では、
- 主人公：選択した行動
- スズマル：選択した行動
を同時に上部へ表示。
現在コマンドを選択しているキャラには「▶」を表示します。

### 戦闘エフェクト
- 通常攻撃：斬撃
- 氷のつぶて / 氷結斬り：氷
- 火炎斬り：炎
- 水のいやし：回復光
- 敵から被弾：赤いフラッシュ

画像生成は使用せず、Canvas描画データのみで実装しています。
