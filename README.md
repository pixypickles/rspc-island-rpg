# りすぺく島RPG Ver.0.77

## ドラゴン挑戦イベントの流れを変更
1. クリア後、タイトルの「ドラゴンに挑戦」を選択。
2. 山頂への道へ入る前に、ドラゴンが五人の頭へ直接語りかける。
   「面白いものを見せてもらった。強き者たちよ、我と腕試しをせぬか？」
   「我に挑む勇気があるなら、火山の頂上へ来るがよい。」
3. 五人が登山道へ入り、雑魚戦・売店・レベル上げをしながら頂上へ進む。
4. 山頂ではドラゴンが再び同じ勧誘をする会話を廃止。
5. 山頂到着演出のあと「ドラゴンと戦いますか？」を表示。
6. 「戦う」から古竜戦を開始。

これにより、ドラゴンの呼びかけ→山頂を目指す→到着→戦闘、という時系列になりました。
