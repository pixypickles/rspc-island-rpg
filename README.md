# りすぺく島RPG Ver.0.42

## 大ドリアングマ戦の修正
大ドリアングマ戦だけ旧式の1人用戦闘開始処理を使っていた問題を修正しました。

現在は戦闘開始時に、
- 主人公
- スズマル
- ユーノ
- ギョウ

のHP・MPを全員分正しく初期化します。

## ギョウ
大ドリアングマ戦にも正式参加します。
ターン順は
主人公 → スズマル → ユーノ → ギョウ → 敵
です。

ギョウの
- 岩守り
- かばう
- 挑発
- 土脈吸収
- 守りの呼吸
- 二段突き
- 迎撃の構え
- 大守護
も使用可能です。

## 戦闘HUD
4人分のHP・MPが上部で重なりにくいよう、表示間隔も少し詰めて調整しました。
