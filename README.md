# りすぺく島RPG Ver.0.44

## 戦闘コマンドが消える問題を修正

原因：
Ver.0.43でギョウを戦闘HUDへ追加した際、
`ensureGyouBattle()` と `isGyouTurn()` を呼び出す処理だけが入り、
関数本体がデータ内に存在していませんでした。

そのため戦闘画面の描画が途中でエラーになり、
下部の「こうげき / スキル / ぼうぎょ / にげる」まで描画されていませんでした。

修正：
- ギョウ用の戦闘初期化関数を追加
- ギョウのターン判定関数を追加
- 4人戦闘でもコマンド欄まで必ず描画
- 縦幅が短いスマホではコマンド欄を少し上へ移動
- タップ判定も表示位置に合わせて調整
