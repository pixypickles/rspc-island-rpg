# りすぺく島RPG Ver.1.16

- ブラックドラゴン／ホワイトドラゴンを全個体 HP4000 に変更。
- 戦闘時の黒白ドラゴンを、山頂の「火山の古竜」と同じ大型ドラゴンシルエットの色違いに変更。
- マップ上の簡易表示は従来どおり。
- 多段攻撃で最後の敵を途中で倒しても、残りのヒット数・ダメージ表示を最後まで続行。
- 氷撃9発などはオーバーキル分も含めた全ヒットの理論合計ダメージを表示。
- ユーノの連射系も最後までヒット表示し、合計値を表示。
- ヤマタノオロチ撃破後も異界の門が残る。
- 門の近くでAを押すと九尾の力で再び開き、HP30000のヤマタノオロチと何度でも再戦可能。
- オロチ撃破後に洞窟から島へ戻ると仲間3人が再合流。
