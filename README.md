# りすぺく島RPG Ver.0.75

## 火山登山道の不具合修正
- 山頂売店に4つ目の項目「店を出る」を追加。
- スマホでは「店を出る」を選んでAボタンで登山道へ戻れる。
- 売店のタップ選択範囲を4項目に対応。
- キーボード上下選択も4項目循環に修正。

## 登山道メニュー
- 登山道でAボタンを押すと通常のフィールドメニューを開く。
- 売店の近くでAを押した場合だけ売店を開く。
- メニューを閉じると登山道へ正しく戻る。

## 登山道の戦闘
- タイトル画面からクリア後モードへ入った際、ページ再読み込みで消えていた
  スズマル・ユーノ・ジュウの加入フラグをクリア済み状態から再構築。
- 登山道の雑魚戦は主人公・スズマル・ユーノ・ジュウの4人戦闘になるよう修正。
