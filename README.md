# りすぺく島RPG Ver.0.65

## 進行不能修正
ユーノ・ジュウが未習得スキルしか持っていない状態で戦闘中に「スキル」を開いても、
必ず下段の「もどる」から行動選択へ戻れるように修正。
未習得スキルは戦闘画面でもグレー表示。

## ユーノのスキルポイント
加入時SP4前後を想定し、1ポイントで大量習得できない構成へ変更。

- 風の癒し：習得2 → Lv2 2 → Lv3 3
- そよぎの輪：習得2 → Lv2 2 → Lv3 3
- 風刃嵐：習得2 → Lv2 2 → Lv3 3
- 疾風：習得3
- 風まとい：習得2 → Lv2 2
- 風護陣：習得3。ただし「風まとい」を先に習得する必要あり

強化効果：
- 風の癒し：Lvごとに全体回復量増加
- そよぎの輪：Lvごとに毎ターン回復量増加。Lv3は持続も延長
- 風刃嵐：Lvごとに全体ダメージ増加
- 風まといLv2：効果時間と回避率を強化
