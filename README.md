# りすぺく島RPG Ver.0.59

## 初期状態の氷結斬り表示を修正

原因：
完全初期化すると主人公の氷結斬りは「未習得（Lv0）」に戻ります。
しかし戦闘画面では未習得でも通常の「氷結斬り MP7」と表示されていたため、
押しても反応していないように見えていました。

修正：
- Lv0では戦闘ボタンを「氷結斬り（未習得）」と明示
- 未習得で押した場合、画面上にも「未習得」と通知
- スキル画面に「SP1で習得」と表示
- heroIceSkill と learned.iceSlash の状態を常に同期
- 習得後は氷結斬り、Lv2は氷結二段斬り、Lv3は氷結三連斬りとして戦闘に反映
- 各強化段階の消費MP表示も実際の値に同期

「初期状態からスタート」は古い育成データを引き継いでいません。
