# りすぺく島RPG Ver.0.32

## たけぞ村・第2陣への準備編
先行部隊撃退後のストーリーを追加。

### ユーノの巨大落とし穴作戦
- 村外に海賊の大部隊が乗れる巨大な穴を作る。
- 土魔法だけでは大工事に間に合わないため、土と風の村人が共同で掘削。
- 土魔法で地盤を割り、風魔法で砕いた大量の土砂を巻き上げて運び出す。
- 海から海水を引き、水魔法でも流れを制御。
- 水面を氷魔法で厚く凍結。
- 最後に土を被せ、普通の地面に見えるよう偽装。

### 調査イベント
ユーノと一緒に
1. たけぞ村近くの海岸
2. 中央火山を望む高台
を調査。

海岸では落とし穴へ海水を引く経路を確認。
火山では風向きと島全体の地形を確認し、後の最終決戦への伏線も少し入れています。

### 今回の終点
巨大落とし穴が完成し、数日後の海賊第2陣襲撃を待つところまで。
