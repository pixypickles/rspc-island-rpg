# りすぺく島RPG Ver.0.17

## 道具屋
「スキルの実」を販売から外し、回復薬に変更。

回復薬：
- 20G
- 何個でも購入可能
- 戦闘中、味方1人のHPを25回復
- 戦闘終了後は従来どおり全回復

メイン戦闘コマンドは
「こうげき / スキル / ぼうぎょ / にげる」
の4つを維持。
回復薬はスキル画面内の「道具：回復薬」として使用できます。

## 火山麓の洞窟
マグマガメまでの道中に雑魚敵を追加。

- ヤキトカゲ
- トウガラネズミ
- イワモグラ

すべてシンボルエンカウント。
避けて進むことも可能。
倒した敵は約12秒後に再出現します。

洞窟の雑魚戦でも主人公＋スズマルの2人が戦闘参加します。
ダッシュミウは引き続き非戦闘同行です。
