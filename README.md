# りすぺく島RPG Ver.1.20

- デスブリザードの表示とタップ判定を `heroHiddenBattleRect()` の1つの矩形定義に統一。
- デスブリザードは x=555～920 / y=478～530 のボタン全域で反応。
- 通常のスキル欄の y<=500 判定より先にデスブリザード専用判定を行うため、左下側・下端側も反応する。
- ブラウザのタブを切り替える、アプリをバックグラウンドへ送る、画面からフォーカスが外れるとBGMを自動停止。
- ゲームへ戻った時だけ、BGM設定がONなら現在の場面の曲を自動再開。
- バックグラウンド中はBGMタイマーとAudioContextを停止し、効果音も鳴らさない。
