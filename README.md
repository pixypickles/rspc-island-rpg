# りすぺく島RPG Ver.0.5

## Ver.0.5 主な変更

### 地理・マップ
- サーカス団拠点：島の北
- ぶりふぉ村：サーカス団から見て南西
- さるびえ村：ぶりふぉ村から南南東
- タイトル画面の五角形配置もこの順序に合わせた
- ダッシュミウがぶりふぉ村まで移動する距離感をさらに強化

### クラウス海賊団
- 一般海賊の姿を獣人化
- ネコ系、ネズミ系、イノシシ系など複数種族を想定
- オレンジ色の海賊衣装は継続

### 主人公スキル
初期スキル：
- 水のいやし（MP5）
- 氷のつぶて（MP4）

### 野生モンスター
スライムを廃止し、植物×動物の可愛いモンスターへ変更。

さるびえ村までに3体：
1. リンゴリス（リンゴ＋リス）
2. モモモモンガ（桃＋モモンガ）
3. カボチャガニ（カボチャ＋カニ）

野生モンスターと海賊団は別々に出現する方針を維持。

スキルメニュー：
- 水のいやし
