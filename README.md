# りすぺく島RPG Ver.0.1

最初の画面確認用プロトタイプです。

## 入っているもの
- タイトル画面
- サーカス団が尾行される短いプロローグ
- ダッシュミウが海賊襲撃から逃れる場面
- ダッシュミウと主人公の簡易ドット絵風表示
- ぶりふぉ村へ向かうフィールド
- スマホ用仮想スティック
- ぶりふぉ村到着イベント
- 主人公が旅立つ決意をするところまで

## 操作
### スマホ
- 左下スティック：移動
- Aボタン：決定
- 会話中：画面タップでも次へ

### PC
- 矢印キー / WASD：移動
- Enter / Space / Z：決定

このフォルダの `index.html` / `styles.css` / `game.js` を同じ階層でGitHubリポジトリへ置けば、そのまま静的ページとして動かせます。
