# りすぺく島RPG Ver.0.73

## クリア後・古竜への登山道
「ドラゴンに挑戦」から即戦闘ではなく、火山頂上までの専用フィールドへ入ります。
強めの魔物4種が配置され、倒して経験値・Gを稼げます。約10秒で復活するためレベル上げ可能です。
右端まで登ると古竜イベント・ボス戦へ進みます。

## 山頂への売店
登山道の序盤に売店を追加。
- 高級回復薬：75G
- 烈風の強弓：260G（ダッシュミウの援護という扱いでパーティ攻撃補助+6）
- 黒曜の剛槍：300G（ジュウ ATK+12 / DEF+5）

## MP対策
- 全キャラクターの「ぼうぎょ」で最大MPの12%（最低4）を回復。
- 主人公に単体MP回復スキル「水脈の雫」を追加。
  - SP1で習得
  - 消費MP6
  - 選んだ味方1人のMPを18回復
