# りすぺく島RPG Ver.1.35

- HP0を「気絶」に変更。気絶中は行動不能でターンを飛ばす。
- 回復魔法・回復アイテムでHPが1以上になればそのまま戦線復帰。
- 全員HP0で全滅。
- 敵ダメージでHPが1に固定されていた処理を0まで減るよう修正。
- ユーノのパッシブ「風脈の息吹」を確認。Lv1は自分の手番開始時MP+3、Lv2はMP+5で機能していた。実際に回復した時は戦闘メッセージにもMP回復量を表示するよう変更。
- ユーノの「風巡りの泉」は従来通り敵ターン終了時に全員MP+5、4ターン（腕輪装備時5ターン）、再使用で残り時間を上書き。


## Ver.1.35
本編ストーリー最初のラスボス（船長＋副船長）のみ少し強化。
- 船長HP: 基礎650 → 800、レベル補正も少し増加。
- 副船長HP: 船長の68% → 78%。
- 副船長「豪斧撃」: 基礎39 → 46。
- 船長斬撃: 基礎22 → 27、後半30 → 36。
- クリア後の海賊拠点戦・はじめから＋には変更なし。


## Ver.1.35
ドラゴンへ挑戦の登山道・複数雑魚戦で、味方の行動後に「敵が攻撃してくる！」のまま停止することがある問題を修正。登山道雑魚専用の敵ターン処理を追加。


## Ver.1.35
- 「ドラゴンに挑戦」登山道の複数雑魚戦で、味方4人の行動後に「敵が攻撃してくる！」のまま停止する問題を再修正。
- 登山道(敵ID 960～963)は通常のフレーム待ち enemyTurn を経由せず、専用敵ターンを即時確定する方式へ変更。
- クリア後簡易島の火山敵(ID 970～973)とは処理・敵配列とも別であることを確認。


## Ver.1.35
- 敵攻撃後に戦闘が停止する根本原因を修正。
- HP0＝気絶仕様追加時の全滅判定 `activePartyKeys()` が、存在しない `partyMembers()` を呼んでいた問題を修正。
- 実際に戦闘へ参加している4人を battle 状態から直接判定する方式へ変更。
- ドラゴン登山道だけでなく、全戦闘の気絶・全滅判定に適用。


## Ver.1.35
- ユーノ「風の癒し」でMPだけ減って回復・ターン進行が止まる問題を修正。
  原因は気絶判定で存在しない `partyMembers()` を呼んでいたため。
- 風の癒しは味方全員を確実に回復し、HP0の味方も回復すれば復帰。その後ユーノの行動を正常終了。
- 「風巡りの泉」の継続MP回復を敵ターン処理から分離。
- 今後は敵の種類に関係なく、次の味方ラウンド開始時に参加中の全員がMP+5。
- 基本4ターン、風刻の腕輪装備時5ターン。再使用は残りターンを上書き。
- 実際に増えたMPを「風巡りの泉：ぴくるす+5 / スズマル+5 ...」と戦闘メッセージに表示。


## Ver.1.35
- 封印の洞窟のブラックドラゴン／ホワイトドラゴンを撃破後3秒で復活するよう変更。
- 旧セーブで倒されたままの個体も、洞窟に入れば自動的に復活タイマーが始まる。
- 九頭龍前で何度でも経験値2500・1200Gを稼いでレベル上げ可能。
- 主人公の回復スキル Lv.3→Lv.4「九尾大水癒」の九頭龍撃破条件を撤廃。
- Lv.3まで習得済みでSP25あれば、その時点でLv.4へ強化可能。
- 九尾大水癒は従来どおり味方全体を最大HPの75%回復。


## Ver.1.35
- 九頭龍の敵ターンをソロ版と4人版で分離。
- ソロ九頭龍：1ターン1回行動。九頭連牙20×9（九尾の衣で10×9=90）、九頭灼炎30×9（九尾の衣で15×9=135）を交互に使用。
