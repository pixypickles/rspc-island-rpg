# りすぺく島RPG Ver.0.45

## ギョウが加入前に表示される問題を修正

原因：
Ver.0.43～0.44の古いセーブ救済処理が強すぎて、
別保存されているギョウのSP・奥義・装備進行などから
「すでにギョウが加入している」と誤判定する場合がありました。

その結果、
- ユーノ加入直後なのにメニューにギョウがいる
- フィールドにはいない
- スキルは選べない
- 一部の戦闘だけ参加する
という不整合が起きていました。

## 修正内容
ギョウの加入状態を `gyouJoinConfirmed` という
ストーリー専用フラグで管理するように変更。

このフラグは実際の「ギョウが仲間になった！」イベント終了時だけ立ちます。

加入前：
- メニューに表示しない
- スキルタブを表示しない
- 戦闘に参加しない
- 敵の攻撃対象にならない

加入後：
- メニューに表示
- スキル選択可能
- 正式に戦闘参加
- フィールド/イベントでも5人編成

Ver.0.44以前のセーブでも、ストーリー地点がギョウ加入前なら
誤って残っていた加入状態を自動で解除します。
