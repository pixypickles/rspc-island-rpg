### ダメージ表示
攻撃が当たった時、敵の上にダメージ数値を表示するようにしました。

単体攻撃：
- 対象の上にダメージ数値をポップアップ表示
- メッセージ欄にもダメージを表示

全体攻撃：
- 各敵の上にそれぞれのダメージ数値を表示
- メッセージ欄にも
  「ヤキトカゲ 12 / イワモグラ 10 / ...」
  のように敵ごとのダメージを表示

属性表示：
- 氷攻撃：ICE
- 炎攻撃：FIRE / FIRE ALL

これで単体・全体とも、実際に何ダメージ入ったか確認しやすくしています。
