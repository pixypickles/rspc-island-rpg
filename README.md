# りすぺく島RPG Ver.0.49

## 決戦前夜パート追加
火山の大ドリアングマ撃破後、すぐ終了せず、たけぞ村へ戻ります。

### 作戦会議
ユーノがここで初めて最終作戦の全貌を説明します。
- 土壁による地上防衛
- 火＋水で霧を発生
- 風で霧を海賊本陣へ移動
- 火山斜面を利用してぶりふぉ村の氷壁前の海賊を崩す
- 5人は気球で上空から海賊船長を奇襲
- スズマルの火で気球を浮かせ、ユーノの風で操縦

### 決戦前の自由準備
作戦会議後に準備画面へ移動します。
- メニューを開いて装備・スキル確認
- 25Gで回復薬を追加補充
- ユーノに話して出撃

### 出撃
ぶりふぉ村の氷壁に亀裂が入ったという急報を受け、
5人と各村の部隊が最終作戦を開始します。

Ver.0.49では最終決戦開始直前まで追加しています。
