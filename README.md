# りすぺく島RPG Ver.0.29

## 修正
- たけぞ村手前の海賊小隊を必ず3部隊配置。
- Ver.0.28の途中セーブで3部隊目が欠けた場合も補修。
- 各小隊との戦闘は3～5体の海賊。
- ユーノがたけぞ村手前の戦闘に正式参加。
- 戦闘HUDにもユーノのHP/MPを追加。
- 敵もユーノを攻撃対象にする。

## ユーノのスキル
SPで以下を習得できます。
- 風の癒し：味方全体回復
- そよぎの輪：味方全体を3ターン徐々に回復
- 風刃嵐：敵全体への風魔法
- 疾風：味方1人を2回行動にする（現段階では主人公対象）
- 風まとい：味方1人の回避率アップ（現段階では主人公対象）
- 風護陣：味方全体の回避率アップ

今後、対象選択UIを作る際に「疾風」「風まとい」は好きな仲間を選べるよう拡張できます。
