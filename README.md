# りすぺく島RPG Ver.0.21

## セーブ / つづきから

タイトル画面に以下を追加しました。

- はじめから
- つづきから

### オートセーブ
フィールド、村、洞窟などをプレイ中、
約1.2秒ごとにブラウザへ自動保存します。

保存内容：
- 現在のエリア
- 主人公名
- 主人公のレベル / EXP / SP / 所持金
- 購入済み装備、回復薬
- スズマルの加入状態
- 火山麓の洞窟進行
- 各フィールド上の現在位置
- 敵シンボルの状態

### 戦闘中に閉じた場合
戦闘そのものの途中経過は保存せず、
直前のフィールド / 洞窟 / 村から再開します。

### 操作
スマホ：
- 「はじめから」「つづきから」を直接タップ

PC：
- ↑↓ で選択
- Enter / Space / Z で決定

「つづきから」はセーブデータがない場合は選択不可です。
