# りすぺく島RPG Ver.0.31

## さるびび村 → たけぞ村の移動マップ
さるびび村を出た後、すぐにたけぞ村へ切り替わらず、
北北東へ進む海岸沿いの1マップを追加しました。

## 海賊団の偵察小隊
移動マップの途中で、ネコ・イヌ・タヌキの海賊偵察小隊3体と強制戦闘になります。

撃退後：
「ここはまだたけぞ村の外」
「ここまで海賊が来ているなら、まさかたけぞ村はもう？」
「急ごう！」
という会話を挟み、そのままたけぞ村へ急ぎます。

## たけぞ村
到着すると、既存の防衛戦イベントへ接続します。
その後は海賊の先行3小隊を撃退する流れです。

移動マップでもAボタンからメニューを開けます。
セーブデータには移動マップの位置と偵察小隊撃破状態も保存します。
