Ver.0.62で一部過去修正が巻き戻っていたため、現在版へ統合し直しました。

### 未加入キャラクター
- スキル画面では全員「???（未加入）」
- ステータス画面も未加入枠は名前・姿・属性・能力値を伏せる

### 主人公
初期状態：
- 水のいやし：使用可能
- 氷のつぶて：使用可能
- 氷結斬り：未習得（SP1）
- 氷晶波：未習得（SP2）

未習得技は戦闘ボタンをグレー表示し、「未習得」と明記。
押した場合も習得方法を表示します。

### スズマル
- 火炎斬り：初期の単体属性技
- 火走り：未習得（SP1）
- 火走り習得後に炎走陣・烈火走陣へ強化可能

戦闘画面でも未習得の火走りを明示します。
