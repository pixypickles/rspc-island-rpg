# りすぺく島RPG Ver.0.51

## 高級回復薬
高級回復薬を追加。
- HP70回復
- 決戦前のたけぞ村で75Gで購入可能
- 通常の回復薬は20G
- 戦闘中のアイテム欄から使用可能

## 主人公：氷結斬り系の強化を戦闘へ反映
スキルツリーの強化段階を実際のダメージ計算へ反映。
- Lv1 氷結斬り：1ヒット / MP7
- Lv2 氷結二段斬り：2ヒット / MP9
- Lv3 氷結三連斬り：3ヒット / MP11

戦闘メッセージにも各ヒットのダメージと合計値を表示します。

## スズマル：単体斬撃を大幅強化
単体特化というキャラクター性を強めるため最大強化を大幅アップ。
- 火炎斬り
- 爆炎斬り
- 豪炎爆斬（最大強化）

豪炎爆斬は最大強化時に非常に高い単体ダメージになります。

爆炎大剣を入手済みなら、これらの斬撃の後にも
「爆炎大剣の炎の追撃」が発生します。
最大強化時は追撃炎も通常より強くなります。
