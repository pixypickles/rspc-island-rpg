# りすぺく島RPG Ver.1.27

## はじめから＋
4人異界モードで九頭龍を撃破すると、タイトルの「はじめから」の右横に小さく「はじめから＋」が解禁。

- 通常と同じオープニングから開始。
- ダッシュミウがぶりふぉ村へ到着すると二周目専用展開へ分岐。
- 村長「ふむ、ぴくるす、ちゃちゃっと片付けてこい」
- 慌てるダッシュミウを連れて、ぴくるすと2人でサーカス団拠点へ戻る。
- 100人以上の海賊と人質を上空から見下ろす専用カット。
- ぴくるすの「デスブリザード」で拠点全体が真っ白な吹雪に包まれる。
- サーカス団員だけを避け、海賊を一気に無力化。
- 船内へ向かい、船長・副船長・サイボーグのクラウスと戦闘。
- 勝利すると「NEW GAME +」専用エンディング。
- はじめから＋では現在のレベル・九尾装備・習得スキルを保持したまま進むため、育て切ったぴくるすのチート状態をそのまま使用可能。
