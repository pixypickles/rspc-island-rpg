# りすぺく島RPG Ver.0.2

Ver.0.1の見た目と導入を修正したプロトタイプです。

## Ver.0.2の主な変更
- フィールドキャラクターを、単純な四角形主体から一段細かいSFC風の見やすい表現へ変更
- 主人公（水色＋白のキツネ）の衣装を白・黒・水色に
- ダッシュミウをウサギらしい見た目＋ネイビーのサーカススタッフ衣装に
- ダッシュミウがぶりふぉ村へ向かう場面では主人公を表示しないよう修正
- 主人公は「ぶりふぉ村到着イベント」で初登場
- 村・家・木・道・氷壁などの描画を少し細かく調整
- タイトル表記をVer.0.2へ更新

## 現在の範囲
タイトル
→ サーカス団帰還・尾行
→ 夜襲
→ ダッシュミウ単独で脱出
→ ダッシュミウを操作してぶりふぉ村へ
→ 主人公初登場
→ 主人公が旅立ちを引き受ける

## 操作
スマホ：
- 左下スティック：移動
- A：決定
- 会話中は画面タップでも次へ

PC：
- 矢印 / WASD：移動
- Enter / Space / Z：決定

GitHub Pagesへ置く場合は、`index.html`、`styles.css`、`game.js`を同じ階層へアップロードしてください。
