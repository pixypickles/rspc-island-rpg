# りすぺく島RPG Ver.0.23

## スズマルのレベル
- メニューのスズマル欄にLv表示を追加
- 正式加入後、主人公がレベルアップするとスズマルもレベルアップ
- 戦闘中のステータス欄にもスズマルのLvを表示

既存セーブでは、最初に現在の主人公Lvを基準にスズマルLvを設定します。

## 戦闘ステータス表示
固定位置ではなく、スマホのブラウザ上部UIを避ける安全位置から描画する方式へ変更。

主人公：
- 名前
- HP
- MP

スズマル：
- 名前 / Lv
- HP
- MP

短い横画面ではキャラクター表示も少し下げます。

## 野生モンスター命名ルール
「野菜・果物 + 動物」に統一。

さるびび村手前：
- ダイコンフェレット（大根 + フェレット）
- ソラマメテン（そら豆 + テン）
- モモイタチ（桃 + イタチ）

「ハネダイコン」「ワタゲイタチ」は廃止しました。
