## 海賊第2陣
巨大落とし穴完成後、数日経って大軍が襲来します。

- たけぞ村の土魔法で大きな土壁を作って防衛。
- 風・氷・炎の村人が応戦。
- 作戦通り少しずつ後退。
- 風魔法で海賊を落とし穴中央へ誘導。
- 炎魔法は敵ではなく偽装した地面を攻撃。
- 風魔法も亀裂の土を吹き飛ばす。
- 土の下の氷の蓋が崩壊。
- 海賊の大部隊が水を満たした巨大落とし穴へ落下。
- 銃や重い装備も水底へ沈み、海賊は撤退。
