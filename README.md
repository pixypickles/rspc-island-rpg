# りすぺく島RPG Ver.0.33

## 海岸調査
海岸調査を歩けるイベントマップに変更。
途中で強敵「バナナザメ」と戦闘になります。

撃破後、ユーノが
- この一帯はバナナザメの縄張り
- 小舟で海岸へ近づくのは危険
- 海賊が海側から奇襲してくる可能性は低い
と判断します。

## 火山調査
火山への道中を歩けるマップに変更。
- サツマイモイノシシ
- ドリアングマ
が出現します。

両方を倒して高台へ到達すると、ユーノが火山の利用案を検討。

候補：
- 火山斜面から岩を大量に転がし、ぶりふぉ村の氷壁周辺の海賊を崩す
- 氷の道を作り、大量の物資を積んだ氷の船を滑らせる
- 火と風を利用した気球で海賊船へ上空から奇襲

## 最終決戦への構想
ユーノは、
- 地上部隊：土壁で防御
- 火＋水：大量の霧を作る
- 風：霧を海賊本陣へ流す
- 主人公たち：気球で上空から船長へ奇襲
という構想を口にします。

今はまだ第2陣の落とし穴作戦が優先で、
最終決戦案は伏線として残しています。
