# りすぺく島RPG Ver.1.10

- 九尾イベントの進行判定を「九尾装備所持」から「九尾イベントを最後まで見たか」に分離。
- Ver.1.07～1.09で九尾装備だけ先に取得済みになったデータでも、クラウス撃破＋氷撃7発＋氷結三連斬りなら村長から九尾イベントを最初から進行可能。
- 九尾イベント完了後の村長は海賊の話に戻らず、封印の洞窟を促す専用台詞になる。
- 禁断の地はAボタン専用判定で封印の洞窟へ入るよう修正。
- 通り過ぎただけで洞窟へ吸い込まれにくいよう自動接触判定を縮小。
- 封印の洞窟の戦闘は主人公1人専用として初期化し、仲間の未初期化ステータスが混ざらないよう修正。
- 封印の洞窟・九尾イベント中はAボタンを表示。
