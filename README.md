# りすぺく島RPG Ver.0.22.2

## パーティメニュー修正

スズマル正式加入後もメニューに主人公しか表示されていなかった問題を修正。

### ステータス
主人公とスズマルを横並びで表示します。

主人公：
- Lv / EXP / HP / MP / 攻撃 / 防御 / SP
- 水・氷属性

スズマル：
- HP / MP
- 火属性
- 「単体攻撃が得意」の役割表示
- 単体攻撃系 / 全体攻撃系の育成レベル表示

### スキル
上部の
- 主人公
- スズマル
をタップしてキャラクターを切り替えられます。

スズマル画面では、
- 単体攻撃系
- 全体攻撃系
を分けて表示。

今後のスキルツリーでは、
全体攻撃も強化できますが、
単体攻撃系の方が一段階ごとの伸びが大きい設計にします。
