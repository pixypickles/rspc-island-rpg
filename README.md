# りすぺく島RPG Ver.0.50

## 最終決戦・前半を追加

決戦前の出撃後、そのまま終了せず大規模な地上戦へ進みます。

### ぶりふぉ村防衛戦
- 亀裂の入った氷壁を土壁で補強
- 風・氷・炎の村人が予定通り後退し、海賊を誘導
- 水＋炎で大規模な霧を発生
- 風魔法で霧を海賊本陣へ移動
- 土の村人が海賊の進路を制限

### 火山作戦
火山調査で確認していた斜面を利用。
巨大な岩と、氷の滑走路を走る氷舟で
ぶりふぉ村の氷壁前に密集した海賊部隊・砲台を崩します。

### 気球奇襲
地上戦を村人たちへ任せ、5人は気球へ。
- スズマルの火で浮力を調整
- ユーノの風で操縦
- 主人公の水とユーノの風も利用
- 霧に紛れて海賊本陣へ接近

Ver.0.50は海賊船長が5人の接近に気づき、
本陣へ降下を開始するところまでです。

次は船長直属の護衛戦～海賊船長との決戦を予定しています。
