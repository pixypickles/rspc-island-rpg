# りすぺく島RPG Ver.0.26

## さるびび村編 完結

### 夜の尾行
防衛隊長の恋人を、主人公・スズマル・ダッシュミウ・ユーノで追跡。

迷路や複雑なステルスにはせず、
一本道に近い夜道を追うシンプルなイベントです。

### ツキポポ
夜にだけ開き、淡く光る植物。

防衛隊長の恋人は、
弱っていたツキポポを見つけて毎晩世話をしていました。

秘密にしていた理由：
防衛隊長が光る植物を苦手としていると思っていたため。

### 問題解決
防衛隊長は
「苦手ではあるけど、そこまでではない」
と判明。

ツキポポを村で育てることを受け入れ、
防衛隊へ復帰します。

### ユーノ
問題解決後、正式加入。

次の目的地は、たけぞ村です。
