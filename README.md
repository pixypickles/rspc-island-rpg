# りすぺく島RPG Ver.0.18

## 複数敵バトル
火山麓の洞窟の雑魚戦を、1体固定から2～5体のグループ戦へ変更しました。
- 基本は2～3体
- 洞窟の奥では4～5体が出ることもある
- 敵ごとのHPを表示
- 生き残っている敵の数に応じて敵側の攻撃回数も変化
- 多人数戦の経験値・Gを増加

## 主人公
全体攻撃「氷晶波」MP8を追加。
- 敵全体へ氷属性ダメージ
- 雑魚の集団を削る用途
- 単体技より1体あたりの威力は低め

## スズマル
単体火力寄りの役割を明確化。
- 「火炎斬り」の威力を強化
- 単体への主力技
- 全体攻撃「火走り」MP8も追加
- 火走りは全体攻撃だが1体あたりの威力は控えめ

主人公＝集団処理もしやすい万能型
スズマル＝単体への高火力が得意
という方向にしています。
