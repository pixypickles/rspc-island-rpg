# りすぺく島RPG Ver.0.52

## ラスボス「海賊船長」を追加
気球から海賊本陣へ降下した後、会話イベントを経て海賊船長との最終戦になります。

### 仮バランス
制作中のセーブデータが高レベルになっているため、今回は最終的な適正レベルを固定せず仮調整です。
- 基準HP 520
- Lv10を超えた分だけHPが緩やかに増加（最大+360）
- 1回の攻撃によるボスへのダメージは最大180
- HP50%以下で第2段階
- 3ターンごとに味方全体への「一斉薙ぎ払い」
- 第2段階では通常攻撃も強化

ジュウの挑発・大守護、ユーノの回避・回復、主人公＋ユーノの合体技、
スズマルの最大強化斬撃などを活かせる戦闘を想定しています。

撃破後は海賊船長が撤退を命じるイベントへ進みます。
次回以降、最初から通常進行した場合の到達レベルを確認してラスボスの数値を再調整できます。
