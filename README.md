# りすぺく島RPG Ver.0.4

## 主な変更
- 地理の向きを修正
  - サーカス団拠点を北側と想定
  - ダッシュミウは南西方向のぶりふぉ村へ向かう
  - ぶりふぉ村までの移動距離を大幅に延長
  - ぶりふぉ村からさるびえ村へは南南東方向に進む構成へ変更
- 戦闘コマンドを4つに整理
  - こうげき
  - スキル
  - ぼうぎょ
  - にげる
- スキルを選ぶと「水のいやし」を選択できる
- 防御時は次の被ダメージを軽減
- にげるを実装

## スマホ
戦闘中は各コマンドを直接タップしてください。

## PC
- 1: こうげき
- 2: スキル
- 3: ぼうぎょ
- 4: にげる
- スキル画面で X: 水のいやし
