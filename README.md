# りすぺく島RPG Ver.0.10

## オープニング移動マップ改修
サーカス団からぶりふぉ村までを「森を抜ける」構成に変更。

### マップ1：林道〜深い森
- 木の本数を大幅に増加
- 曲がった林道を進む
- ぶりふぉ村はこのマップから見えない
- 海賊側から村の位置が簡単には分からない景観に変更

### マップ切り替え
森の奥まで進むと一度マップが切り替わる。

### マップ2：ぶりふぉ村手前
- 最初は木々に囲まれている
- 進むにつれて森が開ける
- 最後にぶりふぉ村が見える構成

今後も村と村の間は、必要に応じて1〜2回のマップ切り替えを入れ、
次の村の属性へ景色が徐々に変わる方向で制作できます。
