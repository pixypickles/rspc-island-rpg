# りすぺく島RPG Ver.0.78

## ドラゴン呼びかけ
冒頭の不自然な「『ドラゴンに挑戦』を選んだ五人が～」を廃止。
「船長との死闘を終え、五人がようやくひと息ついた、その時だった。」へ変更。

## 山頂売店・専用装備追加
- 水晶の小剣（主人公）360G
  主人公の戦闘スキル消費MPを半減（端数切り上げ）。
- 炎獣のグローブ（スズマル）340G
  スズマルの行動ターンが来るたび攻撃力+2。戦闘中累積。
- 風刻の腕輪（ユーノ）340G
  そよぎの輪、疾風、風の泉、風巡りの泉の継続時間+1ターン。
- 地脈の大盾（ジュウ）360G
  ダメージを受けるたび、被ダメージのおよそ1/6だけMP回復（最低1）。
  「土脈吸収」と同時に発動し、両方のMP回復が加算される。

従来の高級回復薬・烈風の強弓・黒曜の剛槍も引き続き販売。
