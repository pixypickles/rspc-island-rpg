## Ver.0.6 主な変更

### ぶりふぉ村長
- 老いた真っ白なキツネとして描画
- 白い毛並み、白いひげ、杖を持つ姿に変更

### レベル・経験値
主人公はLv.1から開始。

戦闘経験値：
- リンゴリス：12 EXP
- モモモモンガ：15 EXP
- カボチャガニ：20 EXP

一定経験値でレベルアップ。
レベルアップ時：
- SP +1
- 最大HP上昇
- 最大MP上昇
- 攻撃力上昇
- 防御力上昇

経験値・レベル・SPはブラウザに保存されます。
