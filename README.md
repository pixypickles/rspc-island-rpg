# りすぺく島RPG Ver.0.18.1

## 修正
2人戦闘でスズマルの行動順になっても、
スキル欄の表示だけ主人公用になることがある不具合を修正。

現在の行動キャラを一か所で判定するようにし、
スズマルのターンでは必ず以下を表示します。

- 火炎斬り MP5（単体・高威力）
- 火走り MP8（敵全体）
- 回復薬
- もどる

## スズマルの育成方針
今後のスキルツリー用に、
「単体攻撃」と「全体攻撃」を別系統として扱う内部データを追加。

単体系：
- スズマルの本命
- 1段階強化するごとの火力上昇を大きく設定
- 他キャラより単体火力が高くなる方向

全体系：
- 火走り系を強化可能
- 雑魚戦にも対応できる
- 強化はできるが、単体系ほど1体あたりの火力効率は伸びない

現時点ではスキルツリー画面そのものはまだ追加せず、
後から育成画面を作りやすい内部構造だけ先に入れています。
