# りすぺく島RPG Ver.0.22.1

## 敵の攻撃表示を修正
以前は敵の攻撃処理後すぐ主人公のターンへ戻っていたため、
攻撃メッセージがほぼ見えず「-2」などの数字だけ残っていました。

修正後：
1. 主人公の行動
2. スズマルの行動
3. 「敵が攻撃してくる！」表示
4. 各敵が攻撃
5. 約1.15秒、攻撃内容を表示
6. 主人公のターンへ戻る

複数敵では、
「ヤキトカゲ → ぴくるす 3 / イワモグラ → スズマル 2」
のように、誰が誰を攻撃したか表示します。

攻撃してきた敵の頭上にも「攻撃！」を表示します。
